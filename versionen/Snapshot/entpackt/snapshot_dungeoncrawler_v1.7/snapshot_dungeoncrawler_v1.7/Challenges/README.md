# Dungeon Crawler v1.7: Challenges

Start dungeon_crawler_challenges.exe from this folder. The program opens directly in Challenges. Only the 16 Challenges are available; the main menu and Seeded Runs are not shown.

Every run uses the standard skin. All six upgrades and all three perks are set to their maximum levels in memory. No player save, rating, selection or highscore is included in this release. Challenge results are created locally after playing.

To rebuild on Windows, run build.bat with raylib installed at C:\raylib. The required source files and game assets are in this folder.
