Dungeon Crawler for Android
The Secret Chambers, version 1.7 (build 1.7.6)

Play
Copy DungeonCrawler_Android_v1.7.apk to your phone and open it.
Allow Android to install apps from that source.
Requires Android 8.0 or newer and an ARM64 or x86-64 device.
The game uses landscape orientation.

Choose SPLIT, FLOAT or D-PAD in Settings. Tap items to use them.
Camera zoom is adjustable. Progress and settings are saved on the device.
The old Android version 1.5 remains a separate app.

Source
Open the project in Android Studio and set up the Android SDK path.
Requires JDK 17+, SDK 36.1, NDK 28.2.13676358 and CMake 3.22.1.
Run gradlew.bat assembleNormalDebug to build the normal app.
The APK is written to app/build/outputs/apk/normal/debug/.

raylib and the required library sources are included.
Library licenses are provided under third_party.
