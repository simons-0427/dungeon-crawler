# Dungeon Crawler

Dungeon-Spiel in C mit zufällig generierter Karte, Gegnern, Schätzen und Items. Das Release enthält die grundlegenden Spielmechaniken.

[Projektseite](https://smstark-projekt.de/projekte/dungeoncrawler.html) | [Downloads](https://smstark-projekt.de/downloads.html)
